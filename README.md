# AgroGestor - Sistema de Gestão Agrícola

Projeto acadêmico desenvolvido para a disciplina
Projeto de Software do curso de Engenharia de Software.

## Objetivo
Desenvolver um sistema para auxiliar produtores rurais
no gerenciamento de suas propriedades agrícolas.

## Funcionalidades
- Cadastro de produtores rurais
- Controle de plantações
- Controle de estoque agrícola
- Relatórios de produção

## Tecnologias
- Python
- Git
- GitHub

## Gerenciamento de Configuração
Este projeto utiliza Git e GitHub para controlar
versões e registrar alterações nos arquivos.
